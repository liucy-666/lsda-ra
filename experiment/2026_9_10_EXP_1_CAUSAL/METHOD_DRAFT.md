> 定位：本文贡献是 **analysis-level 的新视角/新洞察**，不是新模型。
> 因此 Method 节写的是 **"测量与干预框架"**——即"如何把'路由 vs 内容'变成可测量、可证伪的实验"。
> 建议节标题：**3. 面向绑定错误归因的置换干预框架**（而非 "Method"）。

## 3.1 前置：MM-DiT 与残差流

多模态扩散 Transformer（MM-DiT）的每个 block 联合处理图像 token $h \in \mathbb{R}^{N\times d}$ 与文本 token。其残差流更新为

$$h_{\text{out}} = h_{\text{in}} + \text{attn\_gated} + \text{ffn\_gated},$$

其中注意力写入为

$$\text{attn\_gated} = g_{\text{msa}} \odot (W V), \qquad W = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right).$$

我们将 $W$ 称为**路由**（决定从哪些 token 读取、读多少），将 $V$ 称为**内容**（决定读取到什么）。$h_{\text{in}}$ 为残差流，跨层、跨扩散步累积信息。

## 3.2 问题设置与纳入门槛

我们研究描述两个文化实体的提示（实体 A 在左，实体 B 在右）。当 B 区域被绑定到 A 的文化属性（属性漂移）时，该生成**失败**。为确保失败源于**绑定**而非**知识缺失**，仅当

$$\text{standalone A 正确} \ \wedge\ \text{standalone B 正确} \ \wedge\ \text{组合 SS 泄漏}$$

时，该样本才被纳入。判定由两个独立 VLM 完成（泄漏 = 两个裁判对同一侧都判失败）。

## 3.3 置换干预：分离路由与内容

在选定的 (层, 步)，我们**一次前向**同时运行两个提示——混合提示 $p_{AB}$ 与仅含实体 B 的 donor 提示 $p_{B}$（且 B 置于**相同空间位置**）——使两条分支共享同一噪声与布局。读取两条分支（记为 $m$ 与 $d$），在目标区域构造四种注意力输出：

$$O_{\text{mixed}} = W_m V_m,\quad
O_{\text{wfix}} = W_d V_m,\quad
O_{\text{vfix}} = W_m V_d,\quad
O_{\text{donor}} = W_d V_d .$$

其中 $O_{\text{wfix}}$ 只修路由，$O_{\text{vfix}}$ 只修内容。

## 3.4 方向感知归因（核心指标）

朴素的敏感度度量 $\lVert O_{\text{mixed}}-O_{\text{wfix}}\rVert$ 是**有误导性的**：一次替换可以让输出变化很大，却**偏离**正确答案。因此我们改问：**每次替换让输出朝正确答案靠近了多少**：

$$\Delta = O_{\text{donor}} - O_{\text{mixed}}, \qquad
\text{proj}_W = \frac{\langle O_{\text{wfix}}-O_{\text{mixed}},\ \Delta\rangle}{\lVert\Delta\rVert^2}, \qquad
\text{proj}_V = \frac{\langle O_{\text{vfix}}-O_{\text{mixed}},\ \Delta\rangle}{\lVert\Delta\rVert^2}.$$

$\text{proj}_W$（或 $\text{proj}_V$）即"**仅修正路由（或内容）所补上的、朝向正确表示的差距比例**"。该指标是方向感知的，因而排除了"变化大但方向错"的无效替换。

## 3.5 分析协议

- **激活窗口**：晚层 $\{33,34,35,36\}$ × 晚步 $\{24,25,26,27\}$ = 每样本 16 个点。
- **目标区域**：右侧物体的图像 token 区域（各分支完全一致）。
- **聚合**：先在 16 个点上取样本均值，再在 $N$ 个 seed 与 $P$ 个文化对上汇总。
- **Donor**：同一次前向中仅含 B 的条件分支（位置对齐、无重采样）。
- **裁判**：GPT-5.4 + Gemini-3.5-flash；严格双裁判交集判定泄漏。

## 3.6（可选）残差流探针

作为补充探针，我们在选定层/步将目标区域的残差流 $h_{\text{in}}$ 替换为 donor 的对应值。我们将其作为**负面结果**报告：粗暴的残差替换要么不改变绑定（仅最后一层），要么使图像崩溃（多层），说明"内容"与形状/位置相互纠缠，无法通过残差替换单独隔离。

# 写作要点

1. **不要写"我们提出一个新方法"**，要写"我们提出一个**归因框架**"。
2. **强调设计选择**（同前向、位置对齐、方向感知）——这些是让分析**成立**的关键，不是细节。
3. **把 3.4 当成 Method 的心脏**：审稿人会记住"变了≠对了"这一句。
4. **负面结果（h_fix）放 3.6 或附录**，展示诚实性。
5. **与实验节分工**：Method 讲"怎么测"，Experiments 讲"测出了什么"（proj_V 0.82 vs proj_W 0.23）。
