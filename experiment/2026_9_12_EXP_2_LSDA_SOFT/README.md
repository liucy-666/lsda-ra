# 2026_9_12_EXP_2_LSDA_SOFT — LSDA 边界/区域版本消融（v1.1→v1.4 基座决策）

## 目的
解决 clean v1 的 owner mask 边界问题（白缝、锯齿、形状不匹配），并选定后续全量实验的 LSDA 基座版本。所有结论已固化到 `code/lsda/README.md`。

## 版本与结论
| 版本 | 做法 | 结论 |
|---|---|---|
| v1.1 soft | `nearest`→`area` 分数覆盖率池化，凸加权混合 | 消除边缘白缝/阶梯锯齿；代价：**不再严格 one-hot**（审计值非 0 属预期） |
| v1.2 soft+dilate | 图像空间膨胀 `DILATE_PX`（默认 24）填满原生轮廓带 | 消除白缝，但膨胀越大外部漂移越大；**dilate=8** 较平衡 |
| v1.3 no-SAM | 颜色前景分割替代 SAM | **失败**：白瓷与亮背景不可分，mask 退化成半平面 → 崩坏。SAM 不可用朴素颜色分割替代 |
| v1.4 rect | SAM 仅定位 → 外接矩形 + pad，专家在矩形内重生 | pad=0/16 边缘无硬切、外观好；pad=32 背景被重写、漂移大 |

## 基座决策（2026-09-12，最终）
采用 **v1.4 矩形，`LSDA_RECT_PAD=16`、`LSDA_DILATE_PX=0`** 作为后续全量 KA+ME 的 LSDA 基座。
- 明确接受的代价：矩形区域内地面/背景（含底部接触投影）被重写，背景光照不再等同原生。
- v1.2（紧 mask + 软边界）保留为消融/对照。
- 代码：`code/lsda/lsda_pipeline_v11_soft.py` / `v12_soft_dilate.py` / `v13_nosam.py` / `v14_rect.py`。
